DETALLE DE LA INVESTIGACIÓN
MOTOR DE DETECCIÓN

Tres reglas, evidencia visible.

01

Intentos de acceso repetidos

Al menos cinco fallos para una misma cuenta dentro de cinco minutos, incluyendo los extremos. Se evita repetir esta alerta para la cuenta durante cinco minutos.

02

Acceso después de múltiples fallos

Un acceso exitoso después de cinco o más fallos en cinco minutos. Cada acceso exitoso reinicia la secuencia de fallos de esa cuenta.

03

Cambio de permisos

Cualquier cambio entre dos roles diferentes genera una alerta para verificar que estuviera autorizado.

Los umbrales son decisiones de este laboratorio. Las reglas no distinguen por sí solas un ataque de un error legítimo.
